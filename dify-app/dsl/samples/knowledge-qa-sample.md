# 庁内ナレッジ利用規程（サンプル）

本サンプルは OpenGENAI のナレッジ検索（HTTP / MCP）動作確認用です。

## 第1章 目的

本規程は、庁内ナレッジ基盤に登録した文書を、業務上必要な範囲で検索・参照するための基本事項を定める。

## 第2章 タグ運用

1. 検索対象とする文書には、登録時に必ずタグを付与する。
2. タグ未付与の文書は検索対象外とする。
3. 推奨タグ例: `規程`、`マニュアル`、`議事録`。

## 第3章 出典の明示

1. ナレッジ検索の結果を回答に用いるときは、根拠箇所を参照番号（例: [1]）で示す。
2. 構造化登録された文書では、節タイトルおよびページ範囲を出典表示に含めてよい。

## 第4章 資料内検索

特定のファイルについて質問するときは、検索 API の `source`（ファイル名）または `doc_id` を指定し、その文書内に限定して検索する。
