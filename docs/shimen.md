# 紙面

文字、図形、手元の画像を白い紙の上に組む画面です。追加のコンテナはありません。
メニューには常に出ます。非表示にするときは `VITE_APP_HIDDEN_USE_CASES` に `shimen` を入れます。

## 操作

左の列は、上から素材、テキスト、アップロードです。いちばん下の生成で、選んだ文字を書き換えます。
項目はクリックすると紙の中央に置き、紙へドラッグしても置けます。文字はダブルクリックでその場で直します。
選んだ物の上のバーで、大きさ、色、前後を変えます。

上のバーで文書名、戻る、進む、紙のサイズを扱い、右端から PNG をダウンロードします。
紙の下で倍率を変えます。

## 保存

紙面はこのブラウザの `localStorage` にだけ残ります。サーバには送りません。
画像は長辺 1280px 程度に縮めてから保存します。容量を超えると保存できません。

## 生成

文字の書き換えは、ログイン済みの `POST /shimen/rewrite` が既定のチャットモデルを呼びます。
画像を紙に置く操作は、画像生成（`POST /image/generate`）が動いているときだけ使えます。
止まっていても、紙面の編集と PNG の書き出しはできます。
