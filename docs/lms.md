# 研修

研修の動画とテキスト（PDF）をコースにし、誰がどこまで終えたかを残します。
画面は `/lms`、`exAppId` は `lms` です。

- 専用ページ: `/lms`
- フロント: `genai-web/packages/web/src/open-genai/lms/`
- マイクロサービス: `lms-app`（コンテナ `open-genai-lms-app`。ソースは `lms-app/`。FastAPI + SQLite、ポート `8021`）
- Compose profile `lms` で起動します。標準起動には入りません
- ファイルのバイト列は SeaweedFS のプレフィックス `lms/` です。成果物の保持期限では消しません

コース、割当、受講記録は、いま開いている棟の中だけです。
コースを作った人が、そのコースの最初の編集者になります。編集者が認定者を指名します。
教材庫は、その棟の所属者が使います。コースが無くても、動画と PDF を置けます。

修了は、必須の教材（動画・テキスト・確認クイズ）と必須の実技がそろったときです。
受講を開始した人は、その時点の版のまま進みます。

## 起動

```bash
docker compose --profile lms up -d --build
```

未起動のときは専用ページが案内を出します。
動画と PDF の再生 URL は署名付きで、開発では `http://localhost:8333`、本番では `S3_PUBLIC_ENDPOINT` です。
テキストは PDF です。本文はページごと、動画は発話ごとに直し、確定します。文字の少ないページには、画像の説明を足します。動画のフレームは読みません。
