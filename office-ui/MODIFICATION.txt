This browser build of ibisOffice is based on the upstream tag v0.8.7
(https://github.com/ibisjp/ibis-office) with one local change.

The change keeps the opened package so File > Save and the download button
can hand the current bytes to the embedding page under the current name.
File > Save As asks for a name first. Upstream's browser entry reads the
file for display only, then refuses to save it as a new document.

Corresponding source: the v0.8.7 tag archive, plus
office-ui/patches/keep-opened-source.patch in the Open GENAI repository.
